# CampusMarket

Android application for university students to buy and sell second-hand study materials, electronics, and dorm items.

## Features
- Browse campus items in a grid layout
- Filter items by category (Textbooks, Electronics, Dorm, Supplies)
- Search items by name or description
- View item details (price, condition, seller email, location)
- Save items to favorites
- Contact seller button

## Architecture
- MVVM (Model-View-ViewModel)
- UI: Jetpack Compose with Material 3
- Navigation: Navigation Compose with argument passing
- State management: StateFlow and ViewModel
